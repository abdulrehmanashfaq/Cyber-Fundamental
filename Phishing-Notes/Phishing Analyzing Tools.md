## 3. IP Reputation
* **IPinfo** * **Link:** [ipinfo.io](https://ipinfo.io/)  
    * **Core Purpose:** For gathering info about the ip like geographical location and associated organizations.
* **Cisco Talos Intelligence** * **Link:** [talosintelligence.com/reputation_center](https://talosintelligence.com/reputation_center/)  
    * **Core Purpose:** Is a threat intelligence tool from Cisco that enables analysts to assess the reputation of IP addresses, domains, and networks. By submitting an indicator, you can quickly assess whether it has been associated with malicious activity and view its classification.

---

## 4. For URL Visiting
* **urlscan.io** * **Link:** [urlscan.io](https://urlscan.io/)  
    * **Core Purpose:** Is a tool that enables analysts to safely investigate websites without visiting them directly. By submitting a URL, the service simulates a real user browsing session and records all activity generated by the page. It also captures a screenshot of the site and provides insight into its behavior, helping analysts quickly identify suspicious or potentially malicious content.
* **VirusTotal** * **Link:** [virustotal.com](https://www.virustotal.com/)  
    * **Core Purpose:** As we know we can use hashed ip and url for threat modeling.

---

## 5. Online Sandbox Environments for Analyzing Files and Emails
* **ANY.RUN** * **Link:** [app.any.run](https://app.any.run/)  
    * **Core Purpose:** Is an interactive malware that allows analysts to safely execute and observe suspicious files and URLs in real time. Unlike traditional sandboxes, it provides a hands-on experience in which you can interact with the environment, monitor processes, view network activity, and analyze system changes as they happen. This makes it a powerful tool for understanding how malware behaves and identifying key indicators of compromise in a controlled setting.
* **Hybrid Analysis** * **Link:** [hybrid-analysis.com](https://hybrid-analysis.com/)  
    * **Core Purpose:** Is a free malware analysis sandbox that allows analysts to upload and examine suspicious files in a controlled environment. It provides detailed insights into file behavior, including system changes, network activity, and indicators of compromise, helping analysts better understand the potential impact of a malicious file.
* **Joe Sandbox** * **Link:** [www.joesandbox.com](https://www.joesandbox.com/)  
    * **Core Purpose:** Is used to perfome both static and dynamic analysis on files and urls.

---

## 6. Email Analyzer
* **PhishTool** * **Link:** [www.phishtool.com](https://www.phishtool.com/)  
    * **Core Purpose:** It is designed for security professionals across multiple disciplines. PhishTool automates much of the manual work involved in analyzing suspicious emails. Whether you are a SOC analyst triaging user-reported messages, a threat intelligence analyst collecting indicators, or a researcher investigating kits, PhishTool brings everything together in one place. By combining threat intelligence, OSINT, email metadata, and automated analysis workflows, PhishTool provides a centralized view of activity, helping you quickly identify malicious intent and extract valuable indicators of compromise.
